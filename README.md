# Glam Studio - Professional Makeup Artist Website

A modern, responsive website for a professional makeup artist showcasing services, portfolio, and client reviews.

## Project Structure

```
badang website/
├── pages/                 # HTML pages
│   ├── index.html        # Home page
│   ├── portfolio.html    # Portfolio gallery
│   ├── services.html     # Services & pricing
│   ├── reviews.html      # Client testimonials
│   └── contact.html      # Contact form & booking
├── css/                  # Stylesheets
│   └── style.css         # Main stylesheet with responsive design & dark mode
├── js/                   # JavaScript files
│   └── script.js         # Interactive features & form validation
├── images/               # Image assets (placeholder)
└── web design/           # Reference materials
```

## Features

- **Responsive Design**: Mobile-first approach with breakpoints for all devices
- **Dark Mode**: Full dark mode support with smooth transitions
- **Professional Styling**: Based on web design principles
  - Visual hierarchy using typography and color
  - WCAG AA color contrast compliance
  - Minimalist, elegant design
- **Interactive Elements**:
  - Smooth scrolling navigation
  - Form validation
  - FAQ accordion
  - Animated sections
- **Accessibility**:
  - Semantic HTML5
  - Keyboard navigation support
  - Screen reader friendly
  - Focus indicators

## Design System

### Colors
- **Primary**: #8B4789 (Purple)
- **Secondary**: #D4AF37 (Gold)
- **Accent**: #F5E6D3 (Cream)
- **Text Light**: #FFFFFF
- **Text Dark**: #1A1A1A

### Typography
- **Headings**: Segoe UI
- **Body**: System fonts (sans-serif)

## Pages

### index.html
Home page featuring hero section, about, service preview, portfolio preview, testimonials, and CTA

### portfolio.html
Portfolio gallery organized by categories:
- Bridal
- Editorial/Creative
- Events
- Beauty/Daily

### services.html
Complete service offerings with:
- Bridal services (3 packages)
- Editorial & creative makeup
- Beauty & event makeup
- Makeup lessons
- Add-ons section

### reviews.html
Client testimonials featuring:
- Statistics dashboard
- Rating breakdown chart
- 10 verified client reviews
- Service categories

### contact.html
Contact & booking page with:
- Booking form with validation
- Contact information
- Availability schedule
- FAQ section
- Social media links

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)

## Getting Started

1. Open `pages/index.html` in a web browser
2. Navigate through pages using the navigation menu
3. Fill out forms and explore features

## Customization

### Colors
Edit CSS variables in `css/style.css`:
```css
:root {
    --primary: #8B4789;
    --secondary: #D4AF37;
    --accent: #F5E6D3;
    /* ... more variables */
}
```

### Content
Edit HTML files in the `pages/` folder to update content, text, and images
